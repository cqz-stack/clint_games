# Expanding Earth

Race **6 screens** to the gold beacon while the crust heaves. Don't get smooshed.

## Rules

- **5 lives**
- **8 levels** — each level makes you **slower**
- Hazards: falling **tree trunks**, **giant waves** (jump over them), falling **rocks**
- Dense spawns — much harder than the first build

## Controls

- **A / D** or **← / →** — move  
- **W / ↑ / Space** — jump (including over waves)  


## Play

From the **What If?** hub, or:

```bash
/opt/anaconda3/bin/python3.12 earth.py
```
