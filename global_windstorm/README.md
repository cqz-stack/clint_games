# Global Windstorm

Dodge flying debris in a rising gale. **5 storm levels** — each one throws junk faster and more often.

## Controls

- **A / D** or **← / →** — move
- **W / ↑ / Space** — jump (**quad jump**: up to 4 jumps)
- **S / ↓** — duck (on the ground)

Red arrows / outlines mark every incoming throw.

## Play

From the **What If?** hub, or standalone:

```bash
/opt/anaconda3/bin/python3.12 windstorm.py
```
