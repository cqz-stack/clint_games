# Battling Monsters

Survivor.io-style run in an **infinite sandbox**.

- **Move:** WASD / arrows (wand fires automatically)
- **Aim:** press 1–6, then click the ground for rockets, acid, skeletons, whirl, meteors, or termites
- **Gems:** green = 1 XP, blue = 5, gold = 10
- **Level-up:** new attack, upgrade, or amplifier
- **Monsters:** different HP, speed, looks, and attacks (plus mini-bosses)
- **Bosses:** spawn at **player Lv 10 / 25 / 40** — defeat all 3 to clear a normal stage
- **Campaign:** 50 stages — giant boss every 10 (one boss). Beating stage 30 unlocks termites. Beat a stage to unlock the next.

```bash
/opt/anaconda3/bin/python3.12 battling_monsters/monsters.py
```
