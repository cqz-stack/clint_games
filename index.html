How Clint creates games

This is how Clint creates games. There are several steps:

  1. We (me and my dad) think about a game idea together.
  2. we ask ChatGPT to create the spec for the game.
  3. Then we ask ChatGPT to draft the steps for the game and list any gaps so we can address them.
  4. We take the steps, put it into Cursor, and ask Cursor to write the code for the game.

Basically, it's a spec driven AI assisted game development process.
